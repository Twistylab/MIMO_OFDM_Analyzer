# MIMO-OFDM BER Analysis

Проект моделирует цифровую систему связи **MIMO-OFDM** передачи сигнала через канал с рэлеевским замиранием,
многолучевым распространением и АБГШ и сравнивает качество приёма по метрике **BER** для разных
алгоритмов детектирования (**Maximum Likelihood**) / эквализации (**Zero-Forcing**, **Minimum Mean Square Error**)
и демодуляции c жёсткими и мягкими решениями с и без помехоустойчивого кодирования.

Основная цель проекта — исследовать, как меняется **BER** при разных значениях **SNR**,
методах детектирования / эквализации и способах демодуляции сигнала.

## Возможности

- QAM-модуляция и демодуляция через библиотеку `CommPy`
- OFDM-передача с IFFT/FFT, пилотами и циклическим префиксом
- модель MIMO-канала
- канал с AWGN
- канал с рэлеевским замиранием и многолучевым распространением
- сравнение методов **ML**, **ZF**, **MMSE**
- режимы:
  - без FEC
  - FEC + hard decision
  - FEC + soft decision
- расчёт **BER**
- расчёт **EVM** для ZF/MMSE-сценариев
- параллельный запуск независимых расчётов через `ProcessPoolExecutor`

## Назначение файлов

### `optimal_decision_ber_analysis_parallel.py`
Главный модуль проекта. Содержит:

- MIMO-OFDM тракт передачи и приёма;
- прохождение сигнала через канал;
- ML-детекцию;
- ZF/MMSE-эквализацию;
- помехоустойчивое свёрточное кодирование и декодирование Витерби;
- расчёт BER и EVM.

Ключевые классы:

- `QAMModemAdapter`
- `OFDMMIMOTransceiver`
- `DataProcessing`
- `DecisionMethodAnalyzer`

### `ber_multithreaded_computing.py`
Оркестратор параллельных запусков. Запускает BER-анализ для выбранных методов в отдельных процессах
и возвращает результаты в виде словаря.

### `main.py`
Основной сценарий эксперимента. По умолчанию запускает расчёты для:

- `M = 16` - размер QAM модуляции
- `Nt = 2` - количество передающих антенн
- `Nr = 2` - количество принимающих антенн
- `SNR = 0..18 dB` с шагом `2` - отношение сигнал/шум
- всех методов ML / ZF / MMSE
- всех режимов демодуляции (без FEC, FEC + hard decision, FEC + soft decision)
- канала с АБГШ и рэлеевским многолучевым распространением

Скрипт усредняет результаты для нескольких итераций и сохраняет итоговый график BER в папку `ber`.

### `verif.py`
Скрипт верификации. Сравнивает BER, полученный в программе, с эталонными кривыми из готового метода в MatLab (bertool).

По умолчанию использует:

- `M = 4`
- `Nt = 1`
- `Nr = 1`
- `SNR = -10..6 dB`
- АБГШ без рэлеевского замирания и многолучевого канала

### `static_method.py`
Вспомогательный модуль.

Содержит:

- генерацию импульсной характеристики рэлеевского канала с многолучевым распространением;
- учебные реализации `dft`, `idft`, `fft`, `ifft`.

## Как работает модель

Общий пайплайн симуляции:

1. Генерация случайного битового вектора
2. Свёрточное кодирование
3. QAM-модуляция
4. Формирование OFDM-символов
5. Добавление пилотов
6. IFFT и циклический префикс
7. Прохождение сигнала через канал
8. Добавление шума
9. FFT на приёмнике
10. Оценка канала по пилотам
11. ML-детекция или ZF/MMSE-эквализация
12. Демодуляция
13. Hard/soft Viterbi decoding
14. Подсчёт BER
